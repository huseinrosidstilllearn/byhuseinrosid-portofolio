# Portofolio Fotografi Profesional - Husein Rosid

Website portofolio interaktif dan berkinerja tinggi untuk fotografer profesional Husein Rosid. Dibangun dengan pendekatan **Structured Vibe Coding** menggunakan **React 19, TypeScript, Vite, Tailwind CSS, dan Framer Motion**.

---

## 🌟 Fitur Utama
- **Estetika Dual-Theme:** Mendukung *Dark Luxury Editorial* (default) dan *Clean Minimalist Light Mode*.
- **Galeri Foto Interaktif:** Filter kategori dinamis (*Commercial, Portrait, Documentary/Street, Landscape, Wedding*).
- **Rich Lightbox Modal:** Tampilan layar penuh dengan data teknis kamera (EXIF: Shutter, Aperture, ISO, Lensa) serta navigasi keyboard.
- **Photo Essays:** Cerita visual mendalam di balik karya pemotretan.
- **Profil & Gear Kit:** Biografi fotografer, filosofi karya, dan daftar kamera & lensa ("What's in my bag").
- **Reservasi Instan WhatsApp:** Integrasi tombol pemesanan langsung ke chat WhatsApp dengan template pesan otomatis cerdas.
- **Fully Responsive:** Optimal pada layar Ponsel (375px), Tablet (768px), hingga Desktop lebar (1440px+).

## 🚀 Panduan Memulai Cepat

### Prasyarat
- Node.js versi 18+ (disarankan Node.js LTS)
- npm / yarn / pnpm

### Instalasi & Menjalankan Lokal
```bash
# 1. Masuk ke direktori
cd "d:\00 HUSEIN AI PROJECT\By Husein Rosid PORTOFOLIO"

# 2. Instal dependensi
npm install

# 3. Jalankan development server
npm run dev

# 4. Buka di browser
# http://localhost:5173
```

### Build untuk Produksi
```bash
npm run build
```
Folder hasil build `dist/` siap di-deploy ke Vercel, Netlify, atau GitHub Pages.
